# 🛒 GreenKart Automation Framework

A robust Selenium Automation Framework developed using **Java**, **Selenium WebDriver**, **TestNG**, and **Maven** for automating the GreenKart E-Commerce application.

This project demonstrates industry-standard automation practices including Page Object Model (POM), reusable utilities, scalable framework design, and end-to-end test automation.

---

# 📌 Project Overview

GreenKart is an e-commerce application that allows users to search products, manage cart items, apply promo codes, and complete the checkout process.

This framework automates the application's critical business flows while following best practices for maintainability, scalability, and reusability.

---

# 🎯 Objectives

- Automate critical business scenarios
- Improve regression testing efficiency
- Build a scalable Page Object Model framework
- Generate detailed execution reports
- Demonstrate enterprise-level Selenium automation practices

# ▶️ How to Run

## Clone Repository

```bash
git clone https://github.com/<your-github-username>/GreenKart-Automation-Framework.git
```

## Navigate to Project

```bash
cd GreenKart-Automation-Framework
```

## Install Dependencies

```bash
mvn clean install
```

## Execute Tests

```bash
mvn test
```

or

Run

```
testng.xml
```

from your IDE.
